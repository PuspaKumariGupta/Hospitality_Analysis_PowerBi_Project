
# 🏨 Hotel Revenue Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Hotel Revenue Analytics Dashboard** built using Microsoft Power BI. The dashboard provides insights into hotel performance, revenue trends, occupancy rates, and key business metrics across multiple properties in Bangalore.

The primary objective is to analyze hotel performance across different room types, property categories, and time periods to support data-driven business decisions.


## 🎯 Key Features

- **Dynamic Filtering:** Filter dashboard data by city, room type, and week number.
- **Revenue Analysis:** Monitor overall revenue and compare revenue performance across individual properties.
- **Property Performance:** Analyze property-level metrics such as Revenue, RevPAR, ADR, Occupancy, and Realisation.
- **Category-wise Revenue:** Compare revenue contribution between Business and Luxury hotel categories.
- **Weekday vs Weekend Analysis:** Evaluate differences in hotel performance based on day type.
- **Weekly Revenue Trends:** Visualize weekly revenue trends across Business and Luxury categories.
- **Interactive Visualizations:** Explore data through interactive charts, tables, and KPI cards.

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks the following important hotel performance metrics:

| KPI | Description |
|---|---|
| Revenue | Total revenue generated by hotel properties |
| RevPAR | Revenue per Available Room |
| ADR | Average Daily Rate |
| Occupancy % | Percentage of occupied rooms |
| DSRN | Daily Sellable Room Nights |
| Realisation % | Percentage of successful room bookings |
| Cancellation % | Percentage of bookings cancelled |

## 📁 Dataset

The dataset used for this project is stored locally and is not included in this repository.

To explore the dashboard, download the Power BI (.pbix) file and update the data source path in Power BI Desktop to point to your local dataset.

## 🚀 How to Use

1. Clone or download this repository.
2. Download and install [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).
3. Open the `.pbix` file using Power BI Desktop.
4. Update the dataset source path if required.
5. Explore the dashboard using the interactive filters and visualizations.
